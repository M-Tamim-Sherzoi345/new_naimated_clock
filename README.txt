Animated Clock - Android project (package com.animated.clock)

Build the APK (pick one):
A) Android Studio: File > Open this folder > Build > Build APK(s).
   Output: app/build/outputs/apk/debug/app-debug.apk
B) GitHub (no install): push this folder to a new GitHub repo, open the
   Actions tab > "Build APK" > Run workflow, then download the
   Animated_Clock_APK artifact.

Install: copy the .apk to your phone and open it (allow "install unknown apps").
